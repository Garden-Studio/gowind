# Agent notes

gowind is a Go command (`main.go`) that runs the standalone Tailwind CSS CLI
of the release its module version names: module `v4.3.3` runs Tailwind
v4.3.3.

- `release.go` is generated by `go run ./internal/gen vX.Y.Z` from the
  release's `sha256sums.txt`; never edit it by hand.
- The `Follow Tailwind` workflow regenerates it, tests, commits and tags each
  new Tailwind release. A tag is the module version the Go proxy and checksum
  database record forever: never move, delete or reuse one.
- The module path ends in `/v4` because Go requires the major version in the
  path from v2 on. Tailwind v5 needs a `/v5` module path; the workflow only
  warns about it.
- `gofmt -l .` (empty), `go vet ./...` and `go test ./...` must pass.
- Commit titles are [Conventional Commits](https://www.conventionalcommits.org):
  `<type>(<scope>): <what>`, types `feat fix perf refactor docs test build ci
  chore`.
